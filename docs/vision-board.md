# SKOPE 비전 보드 — EXERCISE 6-3

## 비전
교내 문제를 쉽게 신고하고 처리 과정을 투명하게 확인할 수 있는 창구를 만든다.

## 타겟 그룹
교내 문제를 경험하는 학생과 신고를 분류·처리하는 학교 관리자.

## 사용자 니즈
학생은 담당 부서를 몰라도 쉽게 신고하고 진행 상황을 확인하고자 한다. 관리자는 접수된 문제를 분류하고 담당 부서에 전달하며 반복 문제를 파악하고자 한다.

## 핵심 제품 기능
1. 자연어 문제 신고 및 접수
2. AI 신고 내용 분석과 유형 분류
3. 담당 부서 연결 및 재배정
4. 신고 처리 상태와 이력 확인
5. 유사·반복 신고 확인

## 성공 기준 — 과제용 목표, 실제 측정 결과 아님
- 처음 이용하는 학생 5명 중 4명 이상이 도움 없이 3분 이내에 신고를 완료한다.
- 시험용 신고 10건 중 9건 이상에 담당 부서를 연결한다.
- 시험용 신고 10건 모두에서 신고자가 처리 상태를 확인할 수 있다.
